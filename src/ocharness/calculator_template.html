Credits are priced at face value: the plans’ ×3 credit ratio is inherent in the credits (Pro $20 paid → $60 credits, Max $100 → $300 credits), so the rows need no paid-dollar division. The plans’ credits are a monthly grant, so every figure below is a monthly token budget. Each column is an in : out token split from measured runs — real interactive agent sessions (OpenCode, Claude Code logs) sit at 40:1–190:1 raw tokens (60:1 is the conservative pick) — and the custom column prices whatever split you type in the fields above. Real sessions also run ~90% of input as cache reads at a ~0.1x rate, cost-weighting them to ~3:1–6:1: that discount is what the S(x) slider above models — a measured S keeps precedence, and models without a published cached-input discount sit at S(x) ≡ S0. Each cell is the input, output and total tokens the plan’s credits buy at that split. This is a presentation-layer estimate: nothing persisted changes.
